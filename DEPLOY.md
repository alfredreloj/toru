# Toru — Deployment

**Live URL:** https://toru-t5lim.ondigitalocean.app

- **Host:** DigitalOcean App Platform (subdomain auto-generated by DO — it is NOT in
  the code or `.env`; the app builds share links from `req.get("host")` at runtime).
- **Storage:** DigitalOcean Spaces (S3-compatible). Creds live in `.env`
  (`SPACES_*`), which is gitignored. Files auto-expire 24h via a bucket lifecycle
  rule (see `setup-bucket.mjs`).
- **Repo:** https://github.com/alfredreloj/toru

## Upload a file to the live site (no login)

```bash
curl -F "files=@yourfile.ext" https://toru-t5lim.ondigitalocean.app/api/upload
```

Returns JSON with `url` (`/d/<id>`) and `expiresAt`. Verify a link:

```bash
curl https://toru-t5lim.ondigitalocean.app/api/link/<id>
```
